# Nazim Ahmed Portfolio
A responsive multi-page static website using HTML, CSS and JavaScript.

## Run with Live Server
Open this folder in VS Code, right-click `index.html`, and select **Open with Live Server**.

## Included
- Home, About, Projects, Skills and Contact pages
- Supplied profile photo at `public/images/nazim-photo.jpg`
- Supplied original resume at `public/resume.pdf`
- Resume view/download links
- Responsive navigation and validated contact form (opens email client)

## Notes
The resume lists a LinkedIn label but does not include a complete profile URL, so no link has been invented. The Women Safety & SOS project date is retained as “May 8” because the year is not stated.
